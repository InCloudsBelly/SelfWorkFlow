# DocHub 格式与内容守恒

格式适配仍遵守 [内容标准](../../references/wiki-quality.md)。以本次实例的真实预览／阅读页能力为准；以下针对已经出现的 Wiki 写法约束转换，不承诺任意 Markdown／TeX 方言无损。

## 先盘点再转换

固定逐页源 hash 与版本，区分正文／标题／列表、表格、行内代码、各类围栏、真实数学节点、原始 HTML、图块／题注、折叠说明、元数据及链接。读取源端实际使用的解析／渲染配置；用合适的解析器保留位置与上下文，不用跨全文正则替换数学或删除 HTML。工具不可用时人工核对影响范围并记录缺口，不把启发式扫描称作完整 GFM 或语义证明。

为每篇建立源内容→目标表示的对照：正文顺序、条件／版本、表头与单元格、代码、图／题注、公式／原式／式号、折叠标签、引用和附件。授权删改、等价替换、来源节选分别写理由与范围；默认迁移完整正文，摘要只作元数据。

## 实际格式的处理

| 输入 | 转换与核对 |
| --- | --- |
| 正文、标题、列表和强调 | 保留问题、因果、分支、限制与层次，不能丢否定、单位、比较方向或退化条件。按题组织，不以复制段落数量证明语义。 |
| 行内代码与围栏 | 保留原字符及换行语义。`$变量`、`$()`、`TArray<int>`、位运算及 Mermaid 标签中的 HTML 都可能是代码；转换函数只能处理对应上下文。 |
| GFM 表格 | 原始行中的字面竖线须按 GFM 转义，反引号不能保护分列。先从原始代码／数学跨度修正，再解析；不能把已截断的渲染表当完整来源。两端逐行核对表头、完整单元格语义与末列。 |
| HTML 内联／布局 | 空锚点先登记再移除，导出注释与 front matter 不进正文。行内 `span` 就地去标签，不能插入换行拆表头。`br` 转为可辨的换行／分隔，保留独立条件。`<code>` 中实体按该上下文解码一次并转为代码；像 `<ISM>` 的技术占位文本不能误删成空 HTML。 |
| `details`／`summary` | 展开正文并保留 summary 的用途、日期和版本边界；公式复制区仍是源码，不再算一份展示公式。不能删除整块，也不能使旧审计记录混入当前行为。 |
| SVG／Mermaid／图片 | 以真实渲染和核验后的附件承接图，保留题注、图号、读图条件和可维护原图源。SVG 可能含跨空行的 style／defs／marker，须识别完整图块；不只依赖单个 HTML AST 节点，也不全局剥标签。未知渲染器或只剩图源时保持未完成。 |
| 行内／块公式 | 只转换真实数学节点，保留可复制原 TeX。目标不支持原定界符时选经验证的公式图或无歧义记号；复杂排版优先图。显示、原式和正文符号／参数必须一致。 |

## 数学不能靠字符替换推定等价

当前写法包含未加完整花括号的分数参数、根号／指数／嵌套分组、矩阵、对齐和分段环境。向量字形、逐分量乘除、括号、上下标、定义域与单位都可能承载含义。`\gg`／`\ll` 在特定文章中还可能表示位移；不可据字形改成数量级比较。仅靠删命令或几条替换正则不能证明等价。

简单行内式改为可复制记号时，逐项核对指数、分式分组、向量／矩阵角色和源码符号，复用独立内容审查；复杂式保留原 TeX 并用实际支持的渲染器生成媒体。区分语法可解析、数学／来源正确、图片字节相符与阅读页清楚可辨。检查不同主题、宽度、对齐、裁切和复制；未核验项仍为 `unverified`。

## 链接、来源与额度

- 映射键至少包含源页与原锚点；多页可以都有 `wiki-eq-1`。在删除锚点前关联到相应标题、图题、式号或来源条目。跨篇使用真实稳定 ID，章节用实际阅读页的 `id`；字符实体的可见文本、解析后 `href` 和生成 `id` 分别验证，不能互相推定。
- 未取得目标 ID 时保留完整本地稿与待补链计划，不制造正式地址。按已审计划取得 ID 后补链，实际目标及其正文／版本仍需核验；必要来源不能止于空标题、路径或 hash。按命题补入必要且可分享的来源正文，节选须注明范围，不能假称整篇已迁移，也不无限递归复制邻接主题。
- 目录、作者与标签从本次来源／目标规范核实，不复用个人案例值。核 `tags`、`inline_tags`、`effective_tags` 和网页标签，注意 URL 片段、实体编号被误提取的情况；只修误提取，不删除合法标签。
- 生成前按真实单篇／整批限额核算仍保留的旧附件、所有新增图与公式及请求字节。只有输入／角色相同且已核验的媒体可复用。超限按问题与章节分篇并维护导航、编号和映射，或调整经审查的等价表示；不能删图、简化公式或缩正文来假装满足额度。

## 合并验收记录

保留逐页输入／候选／附件指纹、表示替换、定位映射和当前覆盖。分别记录源内容审查、两端解析、源端呈现、目标预览、正式读回、检索、实际网页及适用的独立问答。整库约定覆盖全页；抽样与解析器计数不外推，DOM 指纹只证明所比较的可见单元格，不能证明公式含义或来源命题。

GFM 表格转义与宿主后处理可参考 [GFM 规范](https://github.github.com/gfm/#tables-extension-)；数学节点范围参照本次实际解析器及源端配置。公开规范不能替代当前 DocHub 阅读页的真实能力证据。
