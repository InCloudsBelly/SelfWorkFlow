# 代码审查方法

仅补行为代码审查，沿既有 Review 范围，同版复用。普通解释分析跳过。此法不启动 TDD、构建或写入。

- 从用户约定、契约和真实调用界定支持场景，沿基线和消费者尝试证伪。禁止事后缩小支持范围。以实际入口核对读写、回调、任务完成和保护的先后。有可达失效才报缺陷，证据不足留待核验。
- 共享状态跨尺度、复制重建或跨阶段复用时，用同一可达输入和契约统一表示，比较受影响消费者的实际结果并保留决定性证据。跨发布核对前后的复用和失效入口。
- 跨调用追踪创建、持有、异步等待、发布和释放，检查中途回收、回调和失败退出。以实际持有证明保活。
- 按范围、数量和持有时间区分常驻与临时成本。恢复须重建有效语义，包括适用的优先级、标签和历史。
- 比较删除或内联冗余状态、薄包装、重复遍历及局部替代。核对净减少与影响范围，保留必要恢复、保活、兼容和调试。重构沿既有授权。
