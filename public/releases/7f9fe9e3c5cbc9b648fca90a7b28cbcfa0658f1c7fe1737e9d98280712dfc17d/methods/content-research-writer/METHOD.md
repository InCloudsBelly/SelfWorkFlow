# 研究写作

从本任务已绑定的引用根（文档模式 documentRoot；显式契约用已核验 runtime 根）读取 `references/community-skills/composio-skills/content-research-writer/METHOD.md`，复用当前版本与所需引用身份。只把上游当作研究、结构、引用和迭代方法；当前入口的职责/触发边界优先。

先复用给定材料、已核实证据、受众、篇幅与用户风格。信息充分就写；仅缺关键事实时询问，不重启 Grill、不强制另建写作目录或 Claude 会话。需要新检索时遵守当前来源规则，事实、推断和缺证据分别说明；不得编造引用。

按文章需要安排研究、提纲、草稿或实质改写。保留用户的观点和声音，不给每个小修改强行套一轮研究。已有证据有效时不重复检索；无事实支持的地方列明缺口。

此能力不使用 Composio 连接器，不请求 API key，也不自动发布或发送内容。README 的仓库许可声明与所选 writer 的许可状态保存在固定来源中。

Word/PDF/PPT/表格的实际生成、排版与渲染由已有产物 Skill 负责；明确需要 Obsidian 格式时在成文后按需使用对应入口。存储目的地和知识更新继续遵守当前 owner 与授权。
