# Wiki 引用与跳转清晰度（L1）

L1 是 H3/A4 的共享检查点，不另加权；E2 检查目标/版本，E1 检查证据。评分、状态和关键缺口处理统一按[主标准](wiki-quality.md)，只检查授权内容。

## 按用途安排链接

必要时提供 Wiki 内部跳转或外部链接，让读者知道为何跳、读什么、现在是否必读。当前页在声明先备内讲清直接答案、推导、关键条件和结论；共享契约可链接复用，使用处保留本节所需含义、约束和特有条件，不复制整篇也不只写详见。

| 用途 | 处理方式 |
| --- | --- |
| 必要先备/契约 | 说明需补什么，直达规范章节及版本，读后能接回当前问题。 |
| 选读扩展 | 其他方案、例子或历史与主线区分；不读也能完成本页声明的问题。 |
| 来源证据 | 结论/限制先解释，来源与命题可对应；阅读不必逐条离页，事实核验仍须检查。 |
| 导航 | 按问题/任务/概念分组，标题说明目标；目录可以有多个清晰入口。 |

## 保持路径直接且可结束

- 同页答案优先锚点；跨页直达规范章节，不先绕总目录或多篇参见。标题明确，避免只写这里/更多。一个知识点明确规范入口及版本，不让读者在相似页面间猜测。
- 必要定义与条件就近，选读可放小节末/文末；同目标仅在有定位收益处重现，不把普通名词逐个变成入口或连续重复打断主线。
- 普通互链、返回目录和跨领域联系可以保留；应修复的是必经解释链没有答案或循环回到起点。确需多层先备时给有顺序的阅读路径，说明每步补什么及在哪里结束。
- 不设统一链接数、密度或最大跳数阈值。必要跳转、回跳及新前提可作诊断，但以理解/实施结果判缺口；不能删知识/证据来让网络变小。

## 核对目标、内容和版本

内部使用 Wiki 支持的页面路径、稳定锚点或正式身份，不依赖维护者机器绝对路径。外部优先原始/官方资料、具体章节和适用版本；无锚点时说明章节/条目，不要求整站搜索。
实际核对目标、最终重定向、访问前提、描述和版本；能打开/成功状态不证明内容支持命题。已有有效同版核验可复用，不重复探测所有站点。无法访问或未核对时说明限制，外部原文不代替本页讲解。
必要目标失效时按授权修正或提供可维护的等价契约；无法补齐则保留阅读/实施影响。选读不可访问不自动证明算法错误；关键证据不可核验也不能因正文流畅判可信。

## 两条走查路径

| 对象 | 检查 |
| --- | --- |
| 人类 H3 | 连续阅读回答本页问题；必要跳转要补什么、到达哪节、如何接回；不靠选读/证据原文补缺失主线。目录/来源页按导航/取证职责检查。 |
| Agent A4 | 从正文抽出有界的必要契约、版本和入口；跟随至约束与停止位置，条件与结论配对。不递归展开全部相关页；证据虽非阅读前提，仍按 E1 核验。 |

核对全部必要依赖路径及本次新增/修改链接的目标和内容；可读性任务只抽样时披露范围，不外推全库。记录起点、用途→目标/版本→取得的答案→停止位置/缺口，复用同一条走查时分别说明 H3/A4 观察，不额外建引用网络图。
必要入口缺失、解释链无法结束等按关键缺口处理；必要目标不能核验时按未核实处理。没有引用需求不强造链接，也不使 H3/A4 整项不适用。

## 结构示例

这些是假设示例，不是已检查页面或网站。

| 情形 | 处理 |
| --- | --- |
| 当前页讲清无效索引回退，直链同版编码契约，历史放选读。 | 保留：答案完整、细节可定位。 |
| 甲只指乙，乙指丙，丙又指甲，仍无完整答案。 | 补本页答案和边界，直达共享契约；不只删链接。 |
| 连续多个相似参考或每个名词都跳转，未说明哪个必需。 | 首次解释关键概念，按用途合并入口，减少无收益往返。 |
| 清晰总览有多个子主题，或关键结论有多份映射明确的证据。 | 保留，不因链接多扣分。 |
| 无链接，但必需接口契约缺失，Agent 只能自行搜索。 | 缺契约/必要引用，不是高可读性。 |
