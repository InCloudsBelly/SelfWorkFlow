# SelfWorkflow 宿主说明模板

首次接入按 [接入指南](../onboarding.md) 填写下方代码块，将填好的内容作为宿主说明，由宿主实际支持的持久指令加载。本页导读与相对链接留在公共文档中。未知项填“未确认”，缺失项填“未提供”，不要填入凭据。

```text
每个用户顶层任务开始前，实际读取并遵循下列固定工作流入口。
工作流固定入口：<可读取的公共 WORKFLOW.md 文件路径或 URL，不固定 releases 版本>
项目根来源：<本次用户指定或当前工作区明确提供的位置；不能确认时先明确>
文档读取：<实际工具及参数约定>
项目读取／写入／命令执行：<实际工具、权限范围，或未提供>
独立上下文：<创建工具与隔离语义，或未提供>
消息／等待／完成：<实际工具、状态与完成结果的读取方式，或未提供>
专业服务：<本任务需要的 CodeGraph／Wiki 等现有连接，或未确认／未提供>
```

只有入口和工具接线属于这份说明；任务的 `revision`、`documentRoot`、模式、计划与证据留在当前任务上下文，不固化到宿主说明。每次实际使用仍核对当前协议、权限与必要证据。

纯文档接入可以只提供固定入口，其余能力由 Agent 在当前会话按需核对。需要保存时，宿主的持久指令应明确读取这份说明；文件名本身不提供自动加载能力。
