# Wiki 正文契约

新增/实质更新/内容Review 时读；读取/打开不加载，措辞修正只查影响项。实现/复现归[统一指标](wiki-quality.md) A1–A4，本文管表达。默认读者熟悉领域背景（UE专题熟悉UE），无需读源码仍可理解。规则紧凑不能省正文因果、算法、例子或边界。

## 选择主要用途

每页回答一个稳定问题，按读者目标选用途，不机械拆页：

| 主用途 | 写作重点 |
| --- | --- |
| 教程：学习完成任务 | 开篇说明做出什么；逐步给输入、动作、可观察结果，解释紧贴操作。 |
| 操作指南：完成已有目标 | 前提、步骤、判断分支、验收和恢复；必要背景就近简述或直链。 |
| 参考：查准确契约 | 按接口/数据结构组织事实、字段、范围、默认值、约束、错误与版本。 |
| 解释：理解为什么 | 围绕具体疑问展开概念、机制、因果、取舍、替代和边界，实例贯穿。 |

接口表/伪代码/操作例可服务解释主线，用途不豁免实施信息。共享契约可链接，本节结论/特有条件仍在本页；导航/来源页按查找/取证职责组织。

## 用问题展开充分讲解

- 开篇给场景/疑问/易误判现象及阅读收益，按理解依赖推进，标题给问题/结论；不用文件/符号清单代叙事或每节套相同开头/三段论/总结。
- 概念先讲定义、用途、组成/职责、近似区别、条件及正反例，再给符号。首次类/接口交代中文职责、输入输出及链上位置；必要时串入口、owner、生产/变换/消费、持久化/失效/释放。
- 实例串输入/条件、中间状态、结果，数学例可核算；教学值/推导/实测分清，例子不代一般规则或容量/性能证明。关键算法给实现/伪代码、简化边界、版本/位置及解释，不画黑盒。
- 机制章节直接回答前提、失败/边界与反事实，给因果、条件、依据类别及来源；事实/意图/推断/未知分清，新发现补正文。不逐单元套FAQ，疑难才读[边界质询](design-boundary-grilling.md)。
- 排查给观察条件/信号、判断、下一步与局限；对比给固定条件、变量与代价；正常/失败/边界有验收出口，计划不冒称执行。
- 同上下文短页可合并，独立问题并列导航；不按文件/小节/来源数拆页或拼长文。迁移同步目录/链接/锚点/旧入口，保留 canonical 和有效知识/图，不设字数/页数指标。

## 数学帮助理解机制

公式有助解释算法/模型/变换/概率/累计/误差时，读[公式与参数约定](../../sympy/references/wiki-math.md)及已绑定数学方法，按其符号、形状/单位/域、假设、边界/退化与来源要求讲清对应步骤、成立原因和适用条件；普通叙述不强行公式化，不编模型。
可用 SymPy 精确计算/代回/求导并生成 LaTeX，沿同一观察记录假设/结果/来源。Review 合查 H1–H3 的解释/参数、A2/E1 的正确性与 V3 的实际显示，不另起评分。定界符/命令/矩阵/分段须适配目标 Viewer；源码/TeX编译/计算不证明显示。实际页核公式/参数、对齐/换行/溢出/字体回退；不能预览记渲染 unverified，已知不支持/显示错误记缺口，不能报 V3 达标。

## 中文直接、自然、准确

融入 humanizer-zh 中文节奏及 technical-writing 的读者用途/动作/条件/术语；[固定来源及许可](writing-sources.md)仅维护时读，不加载上游或其他风格 Skill。

- 句子讲清动作/判断，主语/对象/指代明确，条件在前、常见情况先讲、例外紧随；长短句自然，复杂因果可长句，不套英文词数或切碎中文。
- 用具体对象/约束/成本/结果替代翻译腔、营销词、空话；删无信息过渡/重复收束，避免机械对照/排比/连环冒号/拔高，不机械禁词。改写不造事实/加强判断或改命令/数值/公式/符号语义。
- 名称、真实符号/文件/flag、大小写/标点/日期一致，项目/用户约定优先；自检并入写作/修订及 H3/E1，不增润色轮次或询问作者声音。
- 论证用段落、并列用条目、操作用编号、比较用表格；不碎片化、不挤步骤或用装饰序号。删重复话，保留实施条件。

## 图表与实际呈现

长篇机制须有帮助理解关系的图解；流程/分支、概念关系、结构/接口/交互、布局、空间/投影、缓存优化各选合适图型。逐页/关键机制判断解释收益，规范图可复用但说明映射/限制，独立难点不靠泛图改标题覆盖，不凑图型/图数。精确算法配必要伪代码；实际配图才读[图解规范](diagrams.md)。

每图有问题、图题、说明及场景实例，解释对象/符号、读序、关系/条件、结果/回退、单位/坐标和边界；图文/来源一致，图源可维护，无图及非颜色说明保留关键关系/数值。

表头对应共同比较问题，每行对象/条件/步骤粒度一致；单位、统计范围、版本、未知/不适用明确。表后讲关键区别/选择依据，复杂因果放正文。保留真实表头，过宽拆比较问题或受控滚动，适用导出跨页有续表语境，图/图注/条件可对应。

关键概念/条件/结论适度加粗，颜色有文字/形状辅助。中文用**仿宋**，数字/西文/符号用**Times New Roman**；核验实际字体/回退，相近字体或CSS声明不算通过。精确接口/字段/配置/路径用可辨底色代码样式，成组代码/定位独立成块；长标识完整可读可复制，不截断或插字符改命令。实际Viewer/导出宽度检查字体、对比、底色、列表、表格、裁切/重叠及复制，不支持就记缺口。字体证据仅复用同字体文件/版本、渲染环境和样式下已核验的字符范围；新增字符、字重、代码/图内样式窄查实际字体/回退，每页布局仍查。

## 引用与维护信息分层

声明先备内讲清主线、直接答案和关键条件；必要契约说明用途并直达适用章节/版本，读后能接回。区分选读、证据和导航，保留有价值的互链/多层先备；不为少链接删知识，不递归展开全部相关页。核对必要依赖和改动链接的目标/内容/版本，疑难才读[L1方法](link-clarity.md)。

正文中文说明已确认、旧版差异、推断和待验证及影响；风险/冲突/未执行验证就近保留。SHA/hash、来源UUID、构建GUID、审计流水放文末“来源与维护注记”，可折叠；可读源码定位仍在相关正文。保留精确身份/证据关系和协议字段，不改Claim/回执/哈希，不删必要源码/测试向量常量。

实施、复现、布局/编解码按A1–A4核对两端/上下游；缺口沿既有后端分级。来源/静态、视觉、编译/测试、设备与复刻分别记录。写作不授权编译、清缓存、实验、业务代码改动或扩大来源。
