# Wiki 分档样例与评分分歧

仅档位难判或有分歧时读取；指标、权重、状态和门槛以[主标准](wiki-quality.md)为准。这是假设案例，不是模型效果实测；一个好片段不代表整项。

假定4位缓存索引中`0x0–0xE`有效，`0xF`判空，关闭/满池时直读：

| 情形 | 判定 |
| --- | --- |
| 已核对源码存在满池回退，正文未讲 | 已确认缺内容，不是未核实；影响A2，若因果/图注也遗漏再影响H2/V2，关键缺口最高3。 |
| 正文与来源均完整、边界/呈现必查已过，但没有独立迁移观察 | 相关项可给4；不因缺5分增量记null。 |
| Reviewer从正文独立抽取契约，选未演示边界值/容量变化，推导两端、布局、回退和联动验收，再核对来源 | 同一次综合观察可分别支持H1/H2、A1–A4、E1等5分；各项仍须满足全部必查，不能代替其他机制/图的覆盖。 |
| 断言编码位宽证明硬件上限，来源不支持 | E1有错误外推，依赖该断言的H2/A2也受影响；核心错误按0，不用其他高分抵消。 |
| 图标签重叠，正文/表格语义完整 | V3按已知呈现缺口评分，不自动否定算法/事实；若根本未渲染则V3未核实、null。 |
| 中文机械排比，但含义/步骤完整 | H3按实际阅读影响处理，表达修订融入本轮；不能仅凭风格不喜欢否定正确事实或加一轮风格Review。 |
| 公式代数正确，却缺关键参数的单位/形状/取值约束，读者无法解释机制 | 按实际缺口影响H1/H2/H3；关键缺口最高3，不能用SymPy结果抵消。非关键缺口按原分档，不按少一个符号机械扣分。 |
| 用关系式及中文解释机制步骤、假设和退化情况，Reviewer代入新边界并核来源 | 一份观察可支撑H项及A2/E1的相应分档；其余必查仍须完成，公式多或使用工具不自动得5。 |
| SymPy复核通过、生成LaTeX，但未在目标Viewer检查 | 数学/执行证据有效，V3相关显示检查仍unverified；已确认不支持或显示错误按已知缺口处理，不能称实际呈现通过。 |
| 只有一个指标适用某维度，该项4 | 维度80，不达90；必须5。十二项均适用仅E1=4也因可信≈86.667不达标。 |

5分须有独立新增的观察/条件变式/抽取结果，不是重复作者答案，也不要求每项各开一次出题和来源扫描。V项须有对应图文及实际呈现证据，不能用文本推演替代；E2还须核对导航/目标和版本。

每个缺口一个ID，只影响实际受损指标，不机械重复扣分。保留作者分（若已有）、独立分、分歧点和证据，核对候选/规则/来源/适用性。由同一Reviewer说明缺的是正文、必需证据、5分增量还是小改进；补证/修文后只复核影响项，不取平均分或小数折中，不新建Reviewer，也不让用户逐项裁分。影响达标的分歧未解决不报达标，不能暗降目标。
