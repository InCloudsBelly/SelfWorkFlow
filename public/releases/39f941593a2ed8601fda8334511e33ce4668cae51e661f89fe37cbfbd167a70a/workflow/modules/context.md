# 上下文压缩与恢复

仅本轮要求保存/压缩当前上下文、从压缩或交接恢复，或宿主明确报告上下文压力时加载。普通续做、换阶段、大代码库、C++ 内存问题、纹理压缩、单纯响应慢、引用材料中的同名措辞均不触发；机制讨论不执行压缩。路由是按需读规则，不是压力监听器；压力未知不猜比例，不按调用次数例行触发。

仅触发时在既有任务记录随变化更新摘要、压缩、恢复三项状态及依据，不另建账本/每轮回执；三项分别判定，不因前项完成推定后项成功。

1. **摘要：未准备／已准备／有缺口。** 复用原交接状态与位置，只归纳新增历史并合并，按路径/决策去重、替换失效项；补决策原因、失败尝试、在途作业及证据入口。标识/错误原样保留，代码/日志留引用。合并内容完整、满足本次续接方式且入口可回读才记已准备；没有载体时在当前对话提供摘要，对跨会话保存记有缺口并明示持久性未验证，不假定可改写宿主摘要或另建平行文件。
2. **压缩：未执行／待确认／已确认／失败。** 单独保存请求只准备摘要。明确压缩请求或宿主压力下，先保存中间状态，在安全边界使用实际可调用接口；不截断在途工具/写入，不改写宿主管理的指令/工具协议。无接口记未执行；已发请求但结果未知记待确认；只有宿主成功结果或可验证的压缩事件才记已确认，明确失败记失败。摘要落盘、提醒、窗口字符下降均不是历史替换证据。无新信息/可执行进展不重复请求，保留恢复入口并继续可安全推进的授权工作。
3. **恢复：未触发／待核对／已核对／有缺口。** 宿主已自动压缩或从已有交接进入时直接核对，不补跑压缩。沿原 revision/documentRoot、输入与阶段，核目标/约束、修改文件与版本、有效决策/证据、未关闭项和下一动作。摘要是待核事实，不新增授权；同范围授权延续。只刷新变化和必要缺口，不重选 latest、重启流程、重扫/重测或例行确认。缺失回原证据局部补读，未知保留 unverified；必要事实及下一步有据才记已核对，否则记有缺口，仅暂停依赖项。恢复核对通过不代表 token/费用收益已验证。

每次恢复核对事实与下一步即可；仅维护调优或显式效果评估时读[效果验证](../references/context-compaction-evaluation.md)，来源沿[提效记录](../references/context-efficiency.md)，均不在日常展开。
