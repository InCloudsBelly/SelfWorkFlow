# Review 模块

本模块管调度/覆盖/隔离/复审，专业 Skill 只补检查项。行为代码审查补[代码审查方法](../../methods/code-quality/references/review-rules.md)，同版复用。

## 调度与输入

- Light 窄结构化自审；Full/Deep（含纯分析）交付前一个独立 SubAgent 合查 Standards/Spec、行为和测试证据。设计/计划/测试设计合并自审；重大架构/安全/持久化/不可逆风险或显式要求才前置 `plan-integrated-review`。机械文档同步窄校验。
- 实施关闭相关 Critical/Important，Minor 有处置；纯审查交付完整发现，不先要求修复，不套实施/TDD/TEA。授权沿入口。
- 交付请求/验收、绑定、方案/实际增量及证据引用（内容/hash）；复审附可达的上次结论与输入版本，缺正文一次补齐。专项按需读，主 Agent 不为交接预读整包。项目 `.selfworkflow/review.yaml` 匹配 Skill 优先。
- 支持时 `fork_turns="none"`，子任务均用最小包，不导入作者推理/完整历史/无关材料。继承主 Agent 模型/推理配置，不读本机 Review 模型配置，不传 model/reasoning_effort 覆盖，不虚构型号/缓存命中。
- Reviewer 只读候选/必要来源并查反例；不调用 CodeGraph/provider、运行验证、写工作区、更新知识或创建下级 Agent。主 Agent 提供图证据，缺证据且依赖它的结论为 unverified；只回发现、证据、覆盖和缺口。

## 覆盖与完成

- 固定用户范围/基线/实际增量/关键约束；未提交审查含暂存/未暂存及相关未跟踪文件。未知前提先查，合并澄清影响结论的缺口/实质选择，不以假设扩成支持场景。按影响纳入调用点/消费者，不扩成整库审计；Light 减深度不漏约定项。
- 既有状态按不变量/输入类别/关键消费者记录版本、已审/待审/阻塞和证据，不建逐行清单。覆盖正常/失败/边界、生命周期、跨组件契约和测试证据，不适用须有据。候选须确认、证伪、范围外或待证据；成立项附可达触发/消费者后果/定位/增量归因，条件风险不冒充缺陷。
- 发现即记，继续约定剩余范围及同根必要相邻链路；不因数量、严重性、建议已足够或软 Token/次数预算漏审。只读审查完成后一次汇总；主 Agent/Reviewer 均核约定项已审或有据不适用、无待审/必要阻塞；合并同根发现，缺项沿原 Reviewer 补齐。读完 diff/宿主 completed 不证明覆盖，覆盖完成不等于通过或穷尽缺陷。
- 禁编译/测试可静态审查，执行记 not-run/unverified，静审不关闭执行缺口。缺口只阻依赖项；用户停止或必要输入确实不可得时，交付发现、未完范围/原因及续审入口，明确“审查未完成”。

## 复审与回传

- 在既有状态区分完整、增量、复用：范围/基线/实际输入/规则/Skill/环境/消费者依赖兼容且上次覆盖完成才复用；指纹覆盖未提交增量；HEAD/字节/dirty 不替代依赖核对。基线不可验证则重建完整覆盖；有效结论不因换阶段重审。
- 修复后核未关闭项及影响的不变量/输入类别/相邻链路；新发现区分原漏检/变更新引入/新前提。集中修复检查共享状态、发布顺序和恢复交互，交付前重核实际增量；仍有效的最窄充分验证不重跑，不按轮数判复审多余。
- 后续回输入版本/上次结论引用、新增/关闭/撤销/重开 ID、复用覆盖/剩余缺口；仅变化项展开证据，复用不消除未关闭项。显式完整报告按请求展开，基线不可达一次补必要正文；其余不重述旧环境/证据。
- 同时最多一个自动审查检查点；可审切片有新输入/失效结论/待补覆盖才再次发审。同一问题无新证据/可执行进展则停自动重审，转补证据/定位矛盾，继续必要覆盖/修复/独立工作。
- 复用同一 Reviewer，按真实工具/运行状态用 `send_message`/`followup_task`/`send_input`；仅不可用、污染或版本不兼容才替换。无清理回执不声称已销毁；普通任务不因缺契约回执阻塞。缺独立能力可继续实施/测试/自审，标未执行/影响，不降模式或反复要豁免；显式独立、契约、Wiki 发布门禁保留，高风险无法自验则暂缓。TEA 仅显式。

## 显式契约

显式契约按[契约入口](../legacy-host.md)补门禁；普通任务不建 PlanGraph/RunLedger 或伪造回执。

[提效来源](../references/context-efficiency.md)仅维护核对，日常不加载。
