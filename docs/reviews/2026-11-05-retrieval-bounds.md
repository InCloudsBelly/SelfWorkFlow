# 通用搜索维护

目标：提高搜索精准度，减少无目的扩围与重复取证；通用于代码、工具、文件、知识库、历史/会话及互联网。来源是用户提供的 VibeUE/Neo4j 对话与本轮维护要求，未核定原会话 token 用量。

共性策略归 `workflow/modules/search.md`，核心入口只保留缺口/范围/工具/扩围约束；研究写作和知识模块按需复用，领域门槛保留。简单查询不加载细则，不新增检索账本、Agent、索引服务或确认轮次。

[固定来源与许可](../../workflow/references/search-guidance.md)：QMD 的意图/歧义与原文核验、ECC 的相关性筛选/术语/缺口迭代、ast-grep-skill 的工具路由/样例校验。保留固定提交和摘要；三份相同 MIT 条款合并，全部作者版权声明保留。既有 Composio 来源摘要与锁一致。

人工静态走查，未运行模型行为评测：

| 场景 | 预期 |
| --- | --- |
| 已知文件/URL/文档ID | 直读或定位路径，不全局发现 |
| 会话工具缺入口 | 只报告该渠道缺口；必要时定向查已有替代渠道，不全仓找源码 |

| 证据充分/简单查值 | 推进或直答，不重复查证/加载全部 Skill 或来源材料 |
