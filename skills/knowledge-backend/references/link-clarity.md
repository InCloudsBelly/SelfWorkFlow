# Wiki 引用与跳转清晰度（L1）

仅必要依赖/循环引用难判时读；日常按[主标准](wiki-quality.md)的H3/A4共享检查，不另加权。E2查目标/版本，E1查证据。

| 链接用途 | 必须清楚的内容 |
| --- | --- |
| 必要先备/契约 | 补什么、规范章节/版本、取得什么答案以及如何接回当前问题。 |
| 选读 | 扩展/历史/其他方案，不读也能完成本页声明问题。 |
| 来源证据 | 先说明结论/限制，出处与命题对应；仍须核验来源。 |
| 导航 | 按问题/任务/概念分组，标题说明目标，允许多个有效入口。 |

声明先备内的主线、直接答案和关键条件在本页讲清；共享契约可直链，使用处保留含义、特有条件及结论。必要时同页锚点，跨页直达规范章节，不只写“详见”或让读者搜全站。多层先备说明顺序、每步补什么及停止位置；普通互链/返回目录不等于循环缺陷。

人类走查复述跳转前问题、所得答案和如何接回；Agent走查抽取必要契约、版本、条件及停止位置。不递归展开所有相关页，不设链接数/密度/最大跳数；不为少跳转删除知识/证据，不另画引用网络。

检查全部必要依赖与本次新增/修改链接的实际目标、内容、锚点、重定向、版本及访问前提，复用有效同版证据不重复探测。内部不用维护者机器绝对路径，外部优先原始/官方的适用章节。能打开不证明支持命题。

记录可并入同一观察：起点→用途/目标/版本→答案→停止位置/缺口。必要入口失效或解释链无答案是缺口，必要目标不能核验是未核实；选读不可访问不自动否定算法。抽样披露范围，不外推全库。

例如甲→乙→丙→甲仍无答案，应补主线并直达共享契约；清楚总览的多个子主题入口或多份对应明确的证据应保留。无链接却缺实施契约也不算高可读性；没有引用需要不强造链接，不豁免H3/A4整项。
