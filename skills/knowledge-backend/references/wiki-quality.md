# 个人 Wiki 质量评价标准

标识：`personal-wiki-deep-clarity-v7`。沿用v5/v6十二项ID、权重、0–5分及数值门槛；合并取证与记录，达标后结束，不逐项刷满分。v7把公式与参数解释融入人类理解，正文仍须充分解释概念、因果、算法、例子与边界。

## 范围与状态

新增、实质更新或明确评估Wiki检查全部适用项；导航/来源/非技术页按职责判断，不整表豁免。读取/打开不加载，措辞/链接修正只查影响项。全库逐页复核授权范围和遗漏，抽样/已列条目全合格不能外推全库。

固定任务、读者、页面、来源/版本、关联契约及候选身份。一份清单对应必要问题/单元、条件、正文锚点、来源和缺口。单元按独立职责、输入输出、不变量或适用条件划分，不按函数计数；Reviewer还须核对是否漏列。缺来源、未写或工具不可用不能缩分母。

| 状态 | 计分 |
| --- | --- |
| 已检查 | 内容和必需证据已核对，含已确认缺失/错误；给0–5整数分，保留权重。 |
| 未核实 | 必需来源/检查缺失，记unverified、分数null；保留权重，相关维度/总分null，不报达标。 |
| 不适用 | 确实不属页面职责或实际机制，给理由并经Reviewer核对；记not-applicable、分数null，排除权重。 |

仅排除有理由不适用的检查点，不豁免仍有必需点的整项；已有合格内容是复用，不是不适用。关键缺口使理解错误或实施所需输入、条件、步骤、输出、边界、失败处理、验收无法确定，受影响项最高3分；决定正确性的事实错误按0分处理。

## 十二项指标

总权重100：人类理解H=30、图解理解V=20、Agent实施A=35、可信与维护E=15。每项须能定位正文与证据，共用观察用同一ID引用。

| ID | 指标/权重 | 必查要求与验收观察 |
| --- | --- | --- |
| H1 | 概念理解/8 | 问题、读者、先备、范围；先定义、用途、组成、职责、近似概念区别与正反例，再给符号。数学参数首次说明含义、输入输出角色、必要类型/形状、单位/维度、域与索引/积分范围，全文一致。脱离源码仍能解释是什么、为何需要、何时适用。 |
| H2 | 因果与取舍/12 | 约束→设计、输入→结果；取舍、不变量、失败/限制、替代依据及条件变化后果。数学关系解释对应机制步骤、为何成立、假设/近似及边界/退化，不能堆符号或编模型。事实、意图、推断分清。 |
| H3 | 叙事与阅读路径/10 | 按读者问题分层，算例/边界/反例充分；有助理解的数学关系用LaTeX配自然中文，不按公式数评分或强行公式化。并列用条目、操作用编号、连贯论证用段落，配必要图解/伪代码和适度强调。L1主线无需选读补齐。 |
| V1 | 图型与场景覆盖/7 | 图对应实际问题、对象、结构/接口及机制差异；按流程、概念关系、布局/对齐、空间/投影、缓存优化、交互选图。可复用规范图并说明映射/限制，不凑图数或杜撰差异。 |
| V2 | 图注与图文一致/8 | 每图有问题、图题、说明及场景实例；符号、读序、关系/分支、坐标/单位、结果与边界可追踪。区分类别/组成/依赖、先后/并行、候选/最终、示意/实测，图文与来源吻合。 |
| V3 | 呈现与无图阅读/5 | 实际阅读宽度核对字体/回退、强调、底色/对比、列表、图例、表格、裁切/重叠及长标识完整可复制。中文仿宋_GB2312，数字/西文/符号Times New Roman；样式声明不算验收。保留可编辑图源及无图、非颜色的关键关系/数值。 |
| A1 | 数据与接口契约/10 | 实际存在的类型、语义、单位/坐标、精度/容量、无效值、布局/对齐/步长；归属及初始化、生产/消费、更新/失效/释放、线程/队列。接口输入输出、前后置、副作用、退出、产物有效时机与失败消费两端吻合；压缩/位打包/索引/池/缓存/裁剪须有范围、编解码、不变量及预期/实测代价。 |
| A2 | 算法与设计边界/10 | 公式/变换、必要短实现或标明简化的伪代码；判断顺序、退出、同步/并发/跨帧。区分版本/工作区、环境、编译支持、运行准入、配置有效值/优先级/组合及回退；适用平台、RHI、Feature Level、Shading Path、材质/视图、宏/CVar有依据。关键单元的目的、前提、不变量、反事实经来源核对，正文有答案。 |
| A3 | 实施与复现/10 | 最小依赖、搭建/移植顺序、每步产物/验收/恢复，区别建议搭建和实际调度；上下游及适用资产/构建产物、序列化/ABI、CPU/GPU布局、Shader permutation、缓存/历史和消费者的联动/兼容/失效。复现目标、环境/输入、配置、操作、观察点、预期/误差、失败信号和恢复有来源，待填项有取得方式；正常、失败及适用边界有出口。 |
| A4 | 语义抽取与依赖/5 | 稳定标题/锚点、统一术语、精确符号及解释；分支、字段、变量、例子、简化边界明确。设计问题可定位直接答案、条件、依据类别与来源；L1必要契约/版本有停止位置，不靠截图、颜色、指代或自行搜源码补答案。 |
| E1 | 事实与证据/10 | 授权来源、路径/符号及版本可追溯；实现事实、记录意图、解释性推断、未知/冲突分开。图文核对来源；源码/静态、视觉、编译/测试、设备/运行分别记录，不把行为当动机、计划/文本走查当运行或复刻成功。 |
| E2 | 组织与维护/5 | canonical、导航、内外链接/锚点/版本/访问前提正确，跨页无矛盾；保留有效旧文/旧图与版本边界。精确身份后移仍可追溯，正确性限制就近可见。 |

L1为H3/A4共享检查，不另加权：声明先备内讲清主线；必要契约直达适用章节/版本并能接回，选读/证据用途分明。E2查目标，E1查证据。核对全部必要路径及本次改动链接，不递归展开全部相关页，不按链接数/跳数评分。

## 分档与达标

按全部适用检查点共同支持的最高整数档评分，不按缺陷数扣分或平均检查点：

| 分数 | 判定 |
| --- | --- |
| 0 | 整体缺失或有决定正确性的错误。 |
| 1 | 只有名称、结论、框图或引用。 |
| 2 | 部分解释，重要关系/步骤/字段/条件待补。 |
| 3 | 主线可懂，但仍需读者补条件、拆步骤或对照材料。 |
| 4 | 全部适用要求完整准确、可定位，通过必需走查；只余不影响理解/实施的小改进。 |
| 5 | 满足4，且独立补充问题、条件变式或语义抽取验证迁移使用；因果、例子/反例及必要图文充分，无隐含关键前提。 |

一次综合走查可支撑多项，分别注明观察，不为每项重出题/查源码；不能代替其他关键机制覆盖。仅缺5分增量可给有证据的4；缺必需证据仍未核实。原始动机未知但行为/边界已核实、推断明示且无关键缺口，不自动扣分。

达标须同时满足：每个适用项≥4，每个有适用项的维度≥90/100，总分≥95/100；授权范围已复核，必要单元/条件无未关闭关键缺口，必需检查有证据，小改进有处置；独立Review通过，影响达标的分歧已解决。自评不能替代独立评价。

```text
总分 = 100 × Σ(适用权重 × 分数 / 5) / Σ(适用权重)
维度分 = 同式，仅取该维度适用项
评分项覆盖 = 已评分适用项数 / 全部适用项数
适用权重覆盖 = 适用权重 / 100，另列维度分母
```

保留原始值，不先四舍五入判通过。未核实使相关维度/总分null；无适用项的维度标不适用，整表不适用不算总分。不同适用集合不排名，全库须每页分别达标。
规划时识别实际必须5分的项：从5降4，维度损失`20×项权重/维度适用权重`、总分损失`20×项权重/全部适用权重`，多项累计。十二项适用时仅A1=4得总分98、Agent≈94.286，可达门槛；仅E1=4得可信≈86.667，不达标；维度仅一项适用则须5。不得为低分事后改适用性、目标或范围。

达标且必要缺口关闭即可结束，不默认全项5或100分。平均分不能抵消核心错误、误导图文、关键缺项或虚称验证。质量不替代授权/来源/发布门禁，协议允许带缺口发布也须明示未达个人标准。95分是约定索引，不是95%理解率；格式/关键词/模型置信度不代替语义验证。

## 合并执行与记录

1. **范围/取证**：复用一份单元/条件清单和来源索引。作者已看来源须披露，不为模拟盲测先造草稿；要回答的问题可写作前列出，来源后发现的机制补回清单。
2. **写作/自检**：按[正文契约](article-contract.md)充分讲解并自检缺口；默认不再生成完整作者分数表。设计答案融入章节，不强制每单元固定FAQ。
3. **独立集中评价**：同一Reviewer先凭候选及显式同版契约检查可回答性，自选边界/反例，再核必要来源与范围遗漏。合并人类复述、数学解释/参数、图文/实际呈现、Agent实施/语义抽取走查，覆盖全部关键机制；复用观察给十二项一次判分，不加评分/风格Reviewer。数学解释归H1–H3，正确性及来源一致性仍查A2/E1，显示查V3；同一缺口只影响实际受损项，不因公式数量或工具使用加分。已有来源暴露须披露，不冒称盲测。
4. **定向修订**：一次汇总缺口/影响项，优先修阻止达标的问题；只复核修订、分歧及受影响上下游，再重算分数。范围漏审须补齐。不能以轮次/时间上限宣称达标；必需证据补不齐就记未核实，沿既有发布协议处置。

同版规则在同一上下文只读一次；角色间传规则/候选/来源绑定、适用项、覆盖清单及增量，无法访问时一次提供必要正文，并确认接收方实际取得。后端发布回执不证明这些质量检查已执行。共享契约核验和来源切片可复用；字体证据还须绑定实际字体文件/版本、渲染器/主题、样式及已核验字符范围，只复用已覆盖部分，新增字符、字重、代码/图内样式须窄查真实字体与回退。每页图文、布局/溢出与必要边界仍检查。候选/契约/来源/规则/渲染环境变化只失效影响项。

紧凑记录包含绑定、一份覆盖清单、共享观察ID、十二项分数/例外/缺口及观察引用、维度/总分和独立结论。逐项仍可追溯，不重抄同一理由/来源/题单；页面/单元/条件计数从同一清单派生，未知分母不报100%。记录留任务/审查材料，不进Wiki开篇，不新增MCP字段或后端状态。

仅按需读：复杂范围/漏项用[覆盖方法](coverage-baseline.md)，前提/反例难判用[边界质询](design-boundary-grilling.md)，分档分歧用[样例](scoring-anchors.md)，依赖路径难判用[L1方法](link-clarity.md)，消费者要求结构化记录用[记录示例](quality-record.md)，实际配图用[图解规范](diagrams.md)。普通评价不遍历这些文件。

旧评价保留旧绑定；升级v6补中文表达/主用途，v6升v7只补适用的数学增量与影响项，不直接改标签或重跑全量评分。SymPy执行、数学正确及目标Viewer实际显示分别留证；LaTeX字符串/TeX可编译不算显示通过，宿主支持未核验记V3相关检查unverified。评分不授权额外编译、实验、清缓存、业务代码改动或扩大来源。
