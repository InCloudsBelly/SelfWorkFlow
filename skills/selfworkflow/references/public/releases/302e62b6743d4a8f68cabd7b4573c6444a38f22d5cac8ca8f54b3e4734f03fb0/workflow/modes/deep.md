# Deep（可选严格模式）

普通 agent-policy 不默认采用本模式。仅在用户/项目指定或 Agent 明确选择采用时适用；深分析措辞、文件数或 profile 名称不自动启用它，也不自动进入契约模式。无需再读 Full。

围绕实际高风险或不确定性加深边界、并发、恢复、安全或性能分析，不为模式扩展目标、文档或团队。行为变更采用 [TDD](../../methods/testing-review-quality/METHOD.md)，交付前一个真实独立 Reviewer；重大架构、安全、持久化或不可逆风险涉及关键方案选择时前置复核。

实施交付时关闭相关 Critical/Important，Minor 有处置；只读审查按请求交付发现与覆盖，不擅自修复被审系统。所选保证无法满足时交付缺口，不冒充通过；复用有效证据，不以计数替代验收或放弃必要工作。

显式 contract-managed Deep 仍执行[契约门禁](../legacy-host.md)，不由本页放宽。
