# 实施与交付参考

按当前需要选择资源，不因阶段、文件数量或 PR 链接预载完整方法；阅读参考不自动采用其中的全部流程。

可自主判断串行、拆分或委派是否有助于目标。只有预期并行/上下文隔离收益值得协调成本时再协作，复用已有分工，不为选方法另派判别 Agent 或建评分表。一般协作不要求票数、DAG 或额外计划门禁；若明确选用 [implement-spec](../../methods/implement-spec/METHOD.md)，则履行该方法本身的规格、依赖、审查和授权要求。

撰写或更新 PR 正文时可用 [PR 方法](../../methods/matt-pocock/pr/METHOD.md)，基于实际变更、验证和风险；正文工作不自动授权 push、merge 或其他发布。

用户明确要求复盘指定会话或成本时用 [retro](../../methods/matt-pocock/retro/METHOD.md)，按指定历史汇总，不在每次修复或交付后自动运行。

交付形式与深度服务用户目标，保留必要结果、证据与缺口，不重述有效旧材料，不因换阶段重复协调、审查或测试。
