# DocHub 扩展

由 Wiki 工作流在用户选择 DocHub 时加载；普通生成、读取和质量审查不需要此扩展。来源可为任意获授权、绑定版本的资料或 Wiki，不要求 SelfOpenWiki。默认交付能按任务、症状及报错检索的[使用与排障指南](../../references/operations-guide.md)，先形成完整指南，再适配 DocHub 格式；原理／实现源稿保留。

明确要求原理全文、按某份已审稿原用途直接适配，或仅修复既有页面格式时沿用，不自动改写成指南；仅提供原理资料作为来源不等于选择原理全文。用途未另指定的功能知识交付按指南处理。“一键适配”执行内容选择／必要指南生成、媒体与格式适配、检查和完整审阅入口交付。内容生成按任务覆盖验收，格式转换则保留选定稿全部内容，不能混为一层或以摘要冒充指南。指南中必要的图、公式、代码和引用仍须完整。

原理与指南是不同用途的文档，分别核稳定 ID、适用版本及维护归属；不借格式适配直接覆盖旧原理页或迁移编辑主源。正式发布沿[发布流程](publish.md)核实实时规范、审阅具体稿件并验收。

Agent 按 [格式与证据](format.md)执行转换，使用当前环境实际可用的 Markdown 解析器、图／公式渲染器及浏览能力。可以编写或复用本次必要的局部脚本，但不依赖某位维护者的脚本、绝对路径、历史批次或固定页面清单。调用远端预览前仍核对本批内容允许发送到该实例。

本地结构、选定稿与目标正文等价性、公式含义、远端预览、正式读回和实际网页分别验收。未知语法、缺图、必要来源或映射未闭合时，保留完整待审稿与具体阻断；不把源码、占位标题或“数量相等”当作成品通过。这个入口不是自动发布授权。
