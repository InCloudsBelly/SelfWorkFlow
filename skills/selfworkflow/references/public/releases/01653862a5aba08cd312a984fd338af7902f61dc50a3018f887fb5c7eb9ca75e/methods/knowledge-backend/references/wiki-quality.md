# Wiki 内容审查

新增、实质更新和明确内容审查按本页。浏览跳过。局部纠错、措辞、链接或排版只核本次变化及受影响依赖。用户明确要求量化评分或按评分门槛验收时才读[数值评分](wiki-scoring.md)。在途任务与历史评分沿原绑定。

## 按页面用途验收

| 核对项 | 通过条件 |
| --- | --- |
| 事实与来源 | 关键结论与获授权的来源、版本及源码位置吻合。区分事实、解释性推断和未知，分别记录静态、运行及呈现证据。 |
| 理解与边界 | 声明先备后能沿正文读懂问题、概念、机制、取舍和适用条件。关键反例、失败及限制就近说明。解释不靠读者猜图或读源码补主线。 |
| 使用与依赖 | 按页面用途给足可执行信息。实施或复现要交代适用版本和环境、输入、步骤、可观察产物、失败与恢复。关键生产和消费契约对得上，包括实际影响结果的单位、布局、并发及失效条件。共享契约直达适用版本和章节，选读与证据分清。导航和来源页按查找、可达及取证验收。 |
| 图文与可读性 | 图表、公式及代码准确可辨，保留关键关系的文字解释与可复制原文。新增或改变公式、复杂图、宽表或长代码时，绑定实际交付的 Viewer 构建、主题及候选，核对受影响的风险。预览可在渲染构建、配置和相关内容一致时复用，独有风险单独核对。 |

明确约定字体或阅读宽度时按约定核验。默认沿用主题样式，数学、代码及图内字体回退在可辨且语义正确时无需返修。静态检查与实际渲染分别记录。公式须在交付端可读且原文可取，目标不支持时验证等价呈现。检查复制时按实际点击定位，浏览器文本可统一换行比较，存档字节另核。必要呈现证据缺失或关键内容不可读须关闭，其他未测项记录影响。

## 审查和停止条件

- 用一份记录绑定本轮范围、候选与来源版本。列关键问题、条件、正文锚点及证据，作者自检，发布前由同一独立 Reviewer 在正式候选上合并核对遗漏、事实、用法和呈现证据。每个主题交接一份记录，只传可达证据的引用和增量。写作按[正文契约](article-contract.md)。
- 会误导理解或实施的错误、关键条件或必要证据缺失、阻断查找或阅读的问题须关闭。不影响验收的小改进可保留。证据不足的结论标未核实并说明影响，按后端协议处理。必要项有据、阻断关闭就结束，记录覆盖、问题和结论即可。
- 专题和全库逐页核对授权范围和适用项。来源、候选、必要依赖和规则仍有效时复用既有证据，抽样不能代替全库覆盖。返修同一 Reviewer 只核改动和受影响项，合并发现，无需再写一份全量报告。要求逐页呈现验收时逐页核对所约定的呈现。
- 内容结论与发布回执分开。发布继续核授权、来源、绑定、独立 Review 与 CAS。无证据的必要项不能靠发布回执关闭。

复杂范围才读[覆盖方法](coverage-baseline.md)，难判断的反例读[边界质询](design-boundary-grilling.md)，跨页依赖疑难读[链接方法](link-clarity.md)，实际配图读[图解规范](diagrams.md)。
