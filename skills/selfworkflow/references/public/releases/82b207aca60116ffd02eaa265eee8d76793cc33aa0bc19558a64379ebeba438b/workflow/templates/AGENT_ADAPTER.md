# SelfWorkflow 宿主说明模板

首次接入按 [接入指南](../onboarding.md) 替换下方入口地址，作为最小宿主说明，由宿主实际支持的持久指令加载。本页导读与相对链接留在公共文档中，不要填入凭据。

```text
每个用户顶层任务开始前，实际读取并遵循下列固定工作流入口。
工作流固定入口：<可读取的公共 WORKFLOW.md 文件路径或 URL，不固定 releases 版本>
```

仅当宿主确实需要额外接线、且已有当前协议与授权依据时，才补充项目根来源、读取方式、项目操作、独立上下文／完成信号或专业服务。每项写明实际工具、参数与范围；未执行的验证明确标记。无此需要时保留上面两行，不为填满模板猜测工具或未用能力。

只有入口和工具接线属于这份说明；任务的 `revision`、`documentRoot`、模式、计划与证据留在当前任务上下文，不固化到宿主说明。每次实际使用仍核对当前协议、权限与必要证据。

纯文档接入可以只提供固定入口，其余能力由 Agent 在当前会话按需核对。需要保存时，宿主的持久指令应明确读取这份说明；文件名本身不提供自动加载能力。
