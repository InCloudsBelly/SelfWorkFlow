# 代码审查

本地单审入口，不加载上游双审正文。

主 Agent 按当前绑定的 [Review 模块](../../../workflow/modules/review.md)调度；已委派的 Reviewer 只执行分配审查，不再派发/重启流程。覆盖、隔离、复审与交付条件只由该模块管理。

固定用户比较基线与增量；未指定先看未提交改动，无改动且基线不明才问。复用请求/规格、真实标准及验证证据，不另建 issue/spec；缺材料记 unverified。

沿受影响路径检查正确性、安全、兼容性、测试与越界；Standards 对真实项目规则，Spec 对真实需求，同次标识两个轴。发现须有可达输入/反例、位置、影响与最小建议。

只审查报告，不擅自修复或运行测试，不调用 provider。
