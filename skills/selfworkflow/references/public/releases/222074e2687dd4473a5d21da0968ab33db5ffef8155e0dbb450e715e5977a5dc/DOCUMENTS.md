# 文档使用约定

本目录是完整规则版本，documentRoot 为其根。相对链接从声明文件解析。方法路由见 [方法索引](methods/INDEX.md)，不依赖原生 Skill。

通用流程、授权和 Review 调度由 WORKFLOW.md 及其模块管理；来源方法只补充专业方法，不另起访谈、确认或审查团队，不执行来源中的宿主安装、hooks 或菜单。

来源方法里的厂商工具、脚本和配置不自动成为当前能力；只使用实际可用且获授权的工具。UI 检索脚本与其原始数据随包提供，按对应方法核验 Python 和执行授权；本包不部署 MCP、Viewer 或其他外部服务。不从文档路径猜测未随包的工具；无法执行的必要步骤报告 unverified。严格 Host 仍须独立提供并验证 runtime/package/receipt，不能以读到文档作为通过。
