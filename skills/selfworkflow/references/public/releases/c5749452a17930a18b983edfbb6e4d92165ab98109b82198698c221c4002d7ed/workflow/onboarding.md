# 新宿主接入

仅用户要求安装/迁移、固定入口不可读或本次必要宿主能力改变时使用。已安装 Skill 且入口可读即已接线；新会话不重新接入，不为此探测全部服务或安装工具。

## “安装工作流”的默认含义

用户要求“安装工作流”“安装 SelfWorkflow”或“更新已安装工作流”时，默认执行当前已确认
来源版本的 **Skill 文档安装**：将仓库 `skills/selfworkflow/` 的完整自包含内容安装到当前
用户的 `.agents/skills/selfworkflow/`。Windows 为 `%USERPROFILE%/.agents/skills/selfworkflow/`；
用户说 `User/.Agents` 时指这个用户级目录，保留标准的 `skills/selfworkflow` 层级。
用户显式指定其他目录、来源、宿主或版本时遵从该范围，不写死维护者用户名或盘符。
这也符合 [Codex 用户级 Skill 目录约定](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。

目标已由 WheelMaker 等宿主的来源联接管理时，保留联接，通过宿主更新对应 Skill 来源，
再回读用户级入口与规则版本；不改造成独立副本，也不手改宿主来源缓存。用户明确要求
“推送当前修改后更新 WheelMaker”时，先提交并普通 push 到已确认远端，再在宿主刷新来源。
仅安装/更新不自动授权 Git 远端发布；已有同范围推送授权则复用。

该请求即授权本次有界安装/更新，不再询问相同范围的“是否安装”。仅讨论安装含义、修改
规则或询问状态不代表立即安装。未特别点名时，不运行旧 Runtime 安装器，不部署外部工具、
修改其他宿主配置、发布远端或重启宿主；这些不是复制 Skill 文档的附带动作。

1. 确认来源、目标的实际绝对路径及现有安装；识别符号链接/junction，不沿未知链接写入。
   已确认的宿主来源联接走上面的宿主更新路径，后续复制步骤只用于直接文档安装。
   从源码维护时先执行仓库要求的 `skill sync/check`；消费已交付的自包含副本时核对入口、
   revision、完整版本目录及引用，不要求消费者生成、创建 venv 或初始化 submodule。
2. 安装内容包括 `SKILL.md`、完整 `references/public`、绑定 release 和随包资源，不能只拷贝
   根入口或当前一份主规则。只操作目标 `selfworkflow` 子目录，不覆盖其他 Skill 或用户规则。
3. 更新前记录已安装版本和将覆盖文件的状态，备份入口与必要文件到 Skill 发现目录之外；
   区分既有发布内容与用户本地改动，不静默覆盖本地定制。同一 revision 的不同内容视为
   冲突，不能重写或删除旧 release；保留在途任务依赖的旧版本，新增版本先完整落地并验证。
4. 新版本完整可读后再切换入口；切换前比较原入口与预检状态，遇并发变化停止受影响动作。
   失败时恢复本次改动的入口/文件，保留既有版本及可恢复状态，不用清空目录或重装掩盖问题。
5. 回读目标 `SKILL.md`、公共入口、revision 和必要引用，核对与来源版本一致；报告安装绝对
   路径、规则版本及检查结果。“文件已安装”与“宿主已发现/新任务已加载”分别记录，未经
   宿主实际验证不声称后者。进行中的任务继续使用原绑定，不因安装而改选 latest。

## 接入与能力核对

1. 没有主任务绑定时，实际读取宿主可访问的固定公共入口及它引用的版本主规则。有 revision/documentRoot 则直接继承，不重读 latest、不找历史安装。
2. 只核对当前操作需要的能力：文档读取；项目文件/命令；独立上下文与完成信号；任务明确命中的专业服务。区分工具已提供、任务已授权、实际执行结果；缺失项记 unverified，不因工具名称或配置声明推断可用。
3. 按主规则选择模式并继续原任务；已完成的读取、选择和授权直接复用，不再走一遍启动流程。专业服务失败仅影响依赖它的动作，不将接入变成环境安装。

固定入口与完整版本目录都须允许宿主读取、遍历。本机盘符不对远程主机自动可见；离线 Skill 需要完整 references/public，不只复制 SKILL.md。入口可读而版本目录拒绝时报告实际路径，不换源掩盖缺口。

只有用户需要持久接线时才用[宿主说明模板](templates/AGENT_ADAPTER.md)，放入该宿主确实支持的全局/项目指令。只保存入口与真实工具差异，不复制规则正文，不固定发布版本；缺少加载机制时说明缺口，不猜配置位置。

首次接线完成简报绑定、当前所需能力、必要缺口和原任务下一步，不重复请求已获授权的确认。文档接通不代表专业工具、模型遵循或独立 Review 已通过；其验证由实际任务负责。
