# 通用搜索

适用代码、工具、文件、知识库、历史/会话及互联网。简单查询沿核心，多轮/歧义/跨源/扩围才读本页；保留领域来源、版本、时效与权限门槛，不自动加载其他 Skill、派 Agent 或安装索引/模型。

- 先定事实缺口、判断用途、范围依据与充分条件；用实体/符号、版本、别名或来源术语作锚点，必要时排除相近概念。精确词优先，词面不一致再补语义；同范围相关词可合查，不照搬用户整句到所有来源或用泛词 OR 撒网，不另开逐次计划/确认。

| 问题/线索 | 优先入口与证据边界 |
| --- | --- |
| 路径/URL/文档ID/文件名 | 对应入口直读原文或定位路径，不重新全局发现 |
| 会话工具能力 | 工具目录→最小只读调用；缺入口只说明该渠道缺口，必要时查已知配置/CLI/API，不全仓找源码 |
| 代码文本/结构/关系 | 分别用精确文本/已有 AST/代码导航或图；模式存疑先核样例，文本命中不证明调用关系 |
| 概念/知识库 | 限集合/类型/实体，关键词或已有语义检索排序后取原文，不全表导出 |
| 历史/会话 | 限项目、路径、版本/时间/事件，先摘要/游标后补记录 |
| 互联网 | 按主题门槛查官方/一手来源，以实体/版本/域名定位；核原文、日期及适用版本后引用，摘要只作线索 |

- 范围须来自输入、目录/集合、报错、定义/调用、引用或已查覆盖。默认排除无关元数据、历史/发布/生成副本、输出/临时/构建/缓存、依赖和资产；有线索才纳入相关排除项/日志/隐藏路径，不为方便扫根、放宽忽略或跨联接。
- 每轮筛选：相关则取上下文，无关则排除，缺口则用新术语/路径/引用改写。无命中先核名称、范围、模式与覆盖，不当作全局不存在；扩源/扩围须有新线索或必要缺口。独立查询可批量，依赖定位的不提前并发；不套固定轮数/文件数/相关性分数。
- 在已有状态复用意图、范围/输入版本、证据与缺口；未变且新鲜的不重查。区分原文事实、推断与未验证，文件/端口存在或搜索排名不替代验证，不另建账本。
- 工具内投影/脱敏，只回所需存在性、路径、计数或上下文，批量合计守预算。超量先核范围/相关性；截断留 `more/范围/缺口`，不冒充未命中或原样重跑。`rg -m` 按文件限量，`max_output_tokens` 只兜底，不替代总量控制。
- 证据足够即推进；完整审计仍跟踪约定覆盖，不以配额或高排名命中代替完成。无新线索且必要缺口无法补齐时报范围与 unverified；输入/版本/依据变化只补影响项。
