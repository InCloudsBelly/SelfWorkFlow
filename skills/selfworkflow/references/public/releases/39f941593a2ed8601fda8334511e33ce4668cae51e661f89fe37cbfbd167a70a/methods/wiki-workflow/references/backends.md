# 交付与可选发布

默认交付原理／实现完整本地候选、可维护媒体、来源与版本索引及审查结论。明确选用指南或双套时按范围生成，DocHub 默认指南；拟发布稿按用户选择或目标默认绑定。只读请求只产发现，候选请求不发布。Git commit／push、服务写入和宿主安装分别核对既有授权。

用户选择来源服务或发布目标后才读取对应适配：

| 目标／来源 | 适配规则 |
| --- | --- |
| 已连接的 SelfOpenWiki | [生命周期与安全读取](../extensions/selfopenwiki/ADAPTER.md) |
| DocHub 格式或正式发布 | [格式、审稿与目标验收](../extensions/dochub/ADAPTER.md) |

SelfWiki 默认只发布按[完整质量标准](wiki-quality.md)生成的原理／实现全文及必要的导航、参考和来源页，保留原理推导、设计取舍、实现路径、关键细节和边界注意事项。使用／调试／排障指南独立交付，只有用户明确要求向 SelfWiki 发布时才纳入。修订和重审沿用所选原稿的用途与正文深度，吸收有据的技术修正，不能以指南或摘要替换技术全文。

来源与发布目标独立。先确定原理／实现或使用／排障的完整内容，再在候选副本做目标格式适配，记录表示替换、媒体和定位映射；保留源稿及各套正文的维护归属。按主题、文档用途与适用版本关联已有稳定 ID，不把同一主题的原理页直接当作指南页覆盖。若目标正文已被独立编辑，重读并合并授权增量，不覆盖其无关更新，也不维护两个未说明权威关系的编辑主源。

发布前对照所选原稿核候选用途与正文完整性，再核来源／分享权限、具体目标和版本、媒体及当前有效批准。严格后端按其真实协议完成，普通本地文件不伪造CAS或回执。发布后读回全文和媒体并核链接／可检索性；将内容、呈现、发布、索引各自的真实状态交付。
