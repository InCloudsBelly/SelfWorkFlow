# 通用搜索

通用检索。简单查询沿核心，多轮/歧义/跨源/扩围或输出量不明才读本页；保留领域版本、时效和权限门槛，不自动加载其他 Skill、派 Agent 或安装索引/模型。

- 先定缺口/用途/范围依据/充分条件；以实体/符号/版本/别名/来源术语锚定并消歧。精确词优先，词面不一致再补语义；同范围相关词合查，不复制整句或泛词 OR 撒网，不另开逐次计划/确认。

| 线索 | 入口与证据边界 |
| --- | --- |
| 路径/URL/文档 ID/文件名 | 直读或定位，不全局发现 |
| 会话工具能力 | 工具目录→最小只读调用；缺口必要时查已知配置/CLI/API，不全仓找源码 |
| 代码文本/结构/关系 | 精确文本/已有 AST/导航/图；存疑模式核样例，文本命中不证明调用关系 |
| 概念/知识 | 限集合/类型/实体，关键词或已有语义排序后取原文，不全表导出 |
| 历史/会话 | 限项目/路径/版本/时间/事件，先摘要/游标后补记录 |
| 互联网 | 按领域门槛查官方/一手来源，核原文/日期/版本后引用；摘要只作线索 |

- 范围来自输入/目录/报错/定义/调用/引用/已查覆盖。排除无关元数据、历史/发布/生成副本、输出/临时/构建/缓存、依赖/资产；线索所指才纳入排除项/日志/隐藏路径，不为方便扫根、放宽忽略或跨联接。续接直达绑定，不枚举 release。
- 命中取相关上下文，无关排除，缺口按新术语/路径/引用改写；无命中先核名称/范围/模式/覆盖，不推成全局不存在。扩源/扩围须新线索或必要缺口；独立查询可批量，依赖定位的不提前并发，不套固定轮数/文件数/评分。
- 工具内筛选/聚合/脱敏；投影前保留源查询退出码/异常和必要错误摘要，按工具语义解释，失败不冒充零命中或完整证据。普通检索每批默认至多 20,000 字符（UTF-16），按回传序列化正文计量限量，`max_output_tokens` 只兜底。超量先收范围，再分片回路径/计数/上下文；限一次回传，不减总覆盖，必要原文按完整逻辑切片续读。
- 截断回 `count/shown/truncated/scope/next`，未知数明示；区分原文存储完整性与入口可用性。复用既有日志/文件/记录定位，恢复遗漏先取原文；入口失效报缺口，确需重查另说明依据。已入上下文的正文不再作参数搬运；缺拦截器不冒称宿主自动强制。
- 复用既有范围/输入版本/证据/缺口，不建账本；相关输入/规则/消费者依赖变化只补影响项，未变且新鲜才复用。P4/服务等动态状态按新鲜度刷新，优先回差异；旧输出不证明当前状态。
- 证据足够即推进，完整审计不以配额/排名代替约定覆盖；必要缺口无法补齐时报范围与 unverified。区分事实/推断/未验证，文件/端口存在不替代验证。
