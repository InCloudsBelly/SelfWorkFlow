# DocHub 扩展

由 Wiki 工作流在用户选择 DocHub 时加载；普通生成、读取和质量审查不需要此扩展。输入是获授权、绑定版本的 Wiki 快照，输出是独立 DocHub 正文、媒体、来源／章节映射与逐层检查记录。来源可以是任意已核实的 Wiki，不要求 SelfOpenWiki。源稿和主质量标准保留。

“一键适配”执行完整的本地适配链：盘点实际内容类型，准备目标稿和媒体，运行检查，交付完整审阅入口及仍需取得的目标信息。不能把源码块当成图、删掉复杂公式或引用后宣称完成。正式发布仍按 [发布流程](publish.md)核实实例与实时规范、审阅具体稿件并验收。

Agent 按 [格式与证据](format.md)执行转换，使用当前环境实际可用的 Markdown 解析器、图／公式渲染器及浏览能力。可以编写或复用本次必要的局部脚本，但不依赖某位维护者的脚本、绝对路径、历史批次或固定页面清单。调用远端预览前仍核对本批内容允许发送到该实例。

本地结构检查、正文等价性、公式含义、远端预览、正式读回和实际网页分别验收。未知语法、缺图、必要来源或映射未闭合时，保留完整待审稿与具体阻断；不把源码、占位标题或“数量相等”当作成品通过。这个入口不是自动发布授权。
