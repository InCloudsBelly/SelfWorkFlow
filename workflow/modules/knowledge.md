# 知识模块

仅约束 knowledge.read/propose/update 与 Wiki，普通代码/Markdown/方案留痕不触发。知识可选，不阻代码交付；稳定结论每任务仅提示一次，不因 profile/链接启动。多轮/跨源检索沿[通用搜索](search.md)，后端门槛保留；纯排版不加载。

## 操作与后端

read 只读，propose 只产候选；update 须写入授权、版本/来源核验、独立 Review 与可恢复发布，CAS/恢复归所选 adapter。直接要求“总结到 Wiki/更新/审核后发布”即对应范围授权；草稿/方案/意图不明不发布。正文/来源用中文，排除凭据、私人推理、临时事务、完整敏感原文和无效结论。
显式后端优先；已选 selfopenwiki 或 knowledge profile、个人 Wiki 未另选后端时用 [SelfWiki 入口](../../skills/kg-selfopenwiki/SKILL.md)，只读当前操作引用，不预载内部 Writer/MCP 全契约。status、路径、读/Viewer、恢复、运行身份归后端；其他 adapter 不调用 SelfWiki。缺能力/漂移记 unverified，继续普通交付并列待同步，不猜模型/数据库/OAuth/路径。

## 代码类 Wiki 的源码理解

新增/实质更新/审查代码类 Wiki 且涉及实现行为时，先在授权来源内按 [CodeGraph 读取模块](codegraph-read.md)核验项目/新鲜度并实际定向查询，再结合当前源码追踪入口、调用、状态/数据流、生产/消费与失败边界。status/preflight/fresh/符号数不算行为证据，排版/登记/评分/旧文不能替代查询。

- 按本主题具体问题查询，补读未覆盖的定义/调用/分支；已返回且未变的源码不重读。同版同范围证据复用，变化只查影响项，不逐页/逐文件重复查询或另建 Topic 图。
- 既有记录保留项目、查询/输入版本、返回符号/路径/源码范围、覆盖警告、已核关系/缺口，Writer/Reviewer 共用；不将旧专题健康检查、孤立片段或归档扩大为本主题全链证明，不新增 MCP 字段/流程。
- include 覆盖按读取模块处理：新鲜度与关系覆盖分开，定向补核缺失/可疑关系；覆盖警告/单次失败不永久豁免其他可查范围。图边/同名/缺边不证明完整行为，缺边不证明无消费者。
- 图不可用/busy/不新鲜沿读取模块共用重试预算，记录失败与图依赖缺口；可直接读源码/手工追踪并保留有据局部结论，不冒称图验证、自动初始化/重建或绕过来源/授权。

浏览、文案/链接/排版及非行为维护不触发源码探索；非代码专题用各自方法。生命周期、质量与发布门禁不变。

## 数学推理与公式

涉及数学/模型/算法/LaTeX 时读[数学方法](../../skills/sympy/SKILL.md)及[公式与参数约定](../../skills/sympy/references/wiki-math.md)，Writer/Reviewer 复用同版规则、来源与计算证据。纯浏览/无数学不加载；数学正确性与页面渲染分验，不接管生命周期或评分。

## 写作与评价

仅新增/实质更新/明确评价读[质量标准](../../skills/knowledge-backend/references/wiki-quality.md)和[正文契约](../../skills/knowledge-backend/references/article-contract.md)，读取/打开不加载，措辞修正只查影响项。按标准共用一份范围/单元/条件、锚点及来源清单；同一 Reviewer 合并取证/走查/评分，缺口细则按需读，不增润色/评分角色。十二项指标、权重、门槛不变，达标即止，不默认满分；质量与发布成功分判，不新增 MCP 字段/确认，不缩减正文讲解。

## 批量调度与开销

- 按依赖分主题；同层不重叠主题用不继承主历史的独立 SubAgent 限并发，各管本主题全部 Page，过大再下钻，预留审查容量。Writer/Reviewer 不跨主题累积上下文，返修沿原 Reviewer。
- 主调度只存版本、依赖/证据引用、状态/缺口，处理共享页/跨主题依赖；子 Agent 仅产私稿/证据，正式 PageJob/发布归主调度及后端协议。
- 集中返修/合批 QA/复用脚本；正文、来源、规则、呈现变化只复核影响项，标签变化不全量重跑，未变合格视图不重截；显式全库逐页覆盖，每页必需呈现仍核验。
- 同根故障的有限诊断预算不因换页/主题/Agent/续接重置，无新证据不重试；仅阻依赖项，后端/宿主修复另核授权。
- 用已有计时/计数，单主题自开始/上次检查点累计90分钟或150次模型请求（含子任务）即查重复工作、留检查点拆分续接；不凭预算停工/报达标。
