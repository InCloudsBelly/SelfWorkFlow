# 检索参考

当定位、消歧、跨源核对或控制大返回需要指导时参考；普通明确查询可直接处理，不因多轮、文件类型或引用自动开启额外流程。

围绕当前缺口选择来源与范围。已有路径、符号、版本、报错或文档标识优先利用；没有命中时先核名称、范围和查询是否有效，不能推成全局不存在。文本命中不证明调用关系，摘要不能替代支持结论的原文；遵守领域版本、时效、权限和一手来源要求。

精确检索、结构导航、图谱或语义查询按问题和实际能力选择；图谱及其他服务仍有各自启用与版本条件，不能因检索需要自行安装、初始化或探测未选服务。范围扩展应有任务范围、新线索或必要缺口的依据；无关生成物、历史、缓存、依赖和资产通常排除，任务实际需要时再纳入。

已知缺口直接取定位或必要原文，未知结构时可先概览，不强制先摘要再补读。优先在工具内投影/聚合/脱敏，按真实宿主回传限制合并控制输出；必要原文按完整逻辑分片，不以字数或调用次数代替约定覆盖，也不要求每次计算固定字符配额。

保留源退出状态和必要错误摘要，失败不能伪装成零命中。展示被截断或省略时，说明实际覆盖、可回读入口及剩余缺口；按工具和任务选择格式，不要求固定字段。原结果可达时从原结果补缺，入口失效则说明依据后重查，不能把展示截断当作原文已丢失。

复用仍适用的证据；输入、规则、环境或消费者依赖变化时补受影响部分，P4/服务等动态状态按新鲜度核对。已有材料足够时推进，不为无新依据的重复检索制造工作；事实、推断和未验证须区分。
