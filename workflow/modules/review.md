# Review 模块

本模块唯一管理调度、覆盖、隔离与复审；专业 Skill 只补检查项。行为代码审查补读[代码审查方法](../../skills/code-quality/references/review-rules.md)，同版复用。

## 调度

- Light 窄结构化自审；Full/Deep（含纯分析）交付前一个独立 SubAgent 合查 Standards/Spec、行为与测试证据；所有模式取消双 Reviewer。
- 普通设计/计划/测试设计合并自审；重大架构、安全、持久化、不可逆风险或显式请求才前置独立 Review（`plan-integrated-review`）。机械文档同步窄校验，不单开审查。
- 实施须关闭相关 Critical/Important，Minor 有处置；纯审查交付完整发现，不要求先修复，不套实施/TDD/TEA。授权沿入口。

## 覆盖与完成条件

- 固定用户范围、比较基线、实际增量、文件/组件及关键行为路径；未提交审查含暂存、未暂存和相关未跟踪文件。按影响纳入调用点/消费者，不扩成无关整库审计；Light 只减深度，不漏约定项。
- 复用已有覆盖记录：范围/输入版本、已审、待审、阻塞、证据，无需另建逐行清单。候选分别确认、证伪、范围外或待证据；成立项附触发条件、消费者后果、定位及增量归因，区分确定后果与条件风险。检查适用的正常/失败/边界、状态/资源生命周期、跨组件契约和测试证据，不适用须有理由。
- 发现即记，继续剩余范围、同根相邻分支/输入类别/消费者；不因发现数量、严重性、建议已足够或软 Token/次数预算停止，也不先要求修复。审查只读，完成后一次汇总。
- 缺口只阻依赖项，可补的本轮补齐；禁编译/测试可静态审查，执行记 not-run/unverified。用户停止或必要输入确实不可得时，交付已知发现、未完范围/原因/续审入口，明确“审查未完成”。
- 主 Agent 与 Reviewer 均须核对：约定项已审或有据不适用，无待审/必要阻塞；合并同根发现并按严重性交付覆盖与缺口。读完 diff 或宿主 completed 不证明覆盖；覆盖完成不等于代码通过或穷尽缺陷。Reviewer 须回报覆盖与剩余项，缺项沿原 Reviewer 补审。
- 复审/续接沿原范围及记录。原覆盖完整有效时仅复核未关闭项和变化影响；漏检的不变量/输入类别/相邻链路须失效补查。集中修复后核对共享状态、发布顺序和恢复路径的交互；最窄充分验证通过且输入未变不重复执行。交付前重核实际增量，未变的有效结论复用。

## 输入、模型与复用

- 主 Agent 一次交付请求/验收、同版绑定、方案/实际增量与证据引用（内容/hash）；引用须可达，不可达时一次补必要正文。专业细则由专项上下文按需读，主 Agent 不为交接预读整包。
- 支持时 `fork_turns="none"`，不导入作者推理/完整历史或无关材料；其他子任务同样默认最小包。继承主 Agent 模型/推理配置，不读本机 Review 模型配置，不传 model/reasoning_effort 覆盖，不虚构型号/缓存命中。
- Reviewer 只读候选/必要来源并检查反例，不得调用 CodeGraph/provider、运行验证、写工作区、更新知识或创建下级 Agent。主 Agent 提供图证据；缺少 CodeGraph evidence 且结论依赖它则该项 unverified。只回传发现、证据、覆盖与缺口。
- 项目 `.selfworkflow/review.yaml` 匹配 Skill 优先，通用方法补充；相同输入/规则/Skill hash 的有效结论复用，变化只失效影响项，必要反例不能省。
- 同一 Reviewer 合并核验 Findings；按真实工具及运行状态选 `send_message`/`followup_task`/`send_input`，仅不可用/污染/版本不兼容才替换。阶段变化不重审，TEA 仅显式启用。
- 以真实完成状态为证；无清理回执不声称已销毁，普通任务不因契约专用回执缺失阻塞。缺独立能力仍可实施/测试/自审，标独立 Review 未执行及影响，不降模式或反复要豁免；显式独立要求、契约、Wiki 正式发布门禁保留，高风险无法自验则暂缓。

## 显式契约模式

首次构造门禁前读 testing-review-quality/references/contract-host.md；保留真实 hash-bound package、receipt、runner、隔离及 created → executed → cleaned 证据，单 Reviewer 仍须独立。reviewModel 仅 null 兼容，拒绝专属模型覆盖；能力不足不降级冒充通过。普通任务不建 PlanGraph/RunLedger 或伪造回执。
