# 代码审查

按[审查指导](../../../workflow/modules/review.md)组织工作，可由主 Agent 直接审查；需要独立复核时才委派，已受委派者执行分配范围，不自行重启流程或扩大权限。不加载上游双审正文。

依据请求确定基线与增量；未指定时可先看未提交改动，确实缺关键比较依据才澄清。复用真实需求、项目标准和有效证据，不为审查另建 issue/spec 或固定字段表。

沿实际受影响路径判断正确性、安全、兼容性及验证缺口；成立的发现说明可达触发、位置、后果与建议，条件风险和缺证据分别表达。用户要求完整范围时不能仅因已有若干发现而停止。

仅要求审查时不擅自修复；额外测试或其他操作须处于授权与环境限制内，不能从“审查”推导编译、写入或服务初始化权限。遵守实际工具协议，只报告实际覆盖与证据。
