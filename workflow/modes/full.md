# Full（可选严格模式）

普通 agent-policy 不默认采用本模式。只有用户/项目指定，或 Agent 明确选择采用本模式时，下述过程保证才适用；阅读本页、任务规模或 profile 名称不自动启用它，也不自动进入契约模式。

采用 Full 时，先明确足以指导实施的方案和验证方式，可复用已有内容，不要求另建文档。行为变更采用 [TDD](../../skills/testing-review-quality/SKILL.md)，交付前由一个真实独立 Reviewer 合查需求、标准、行为和测试证据；重大架构、安全、持久化或不可逆风险涉及关键方案选择时前置复核。

实施交付时关闭相关 Critical/Important，Minor 有处置；只读审查按请求交付发现与覆盖，不擅自修复被审系统。无法满足所选保证时说明未完成范围，不以普通策略或静态结论冒充严格模式通过；有效且未变的证据可复用。

显式 contract-managed Full 仍执行[契约门禁](../legacy-host.md)，不由本页放宽。
